# Principles

PURPOSE: classify every activity as value-adding or waste from the consumer view and eliminate the largest waste first
CONSUMER_DEFINITION: name who receives the output and judges its worth before any analysis
VALUE_DEFINITION: value is what the consumer would knowingly pay for in time, money, or attention
ACTIVITY_CLASSES: value-add, necessary-non-value, waste

# Eight wastes

DEFECTS: rework, bugs, rejected output, correction loops
OVERPRODUCTION: building more or sooner than needed, speculative features, premature generalization
WAITING: idle time blocked on review, build, approval, or handoff
UNDERUTILIZATION: capable people or tooling doing rote work a cheaper mechanism handles
TRANSPORTATION: needless movement of artifacts between systems, repos, formats, teams
INVENTORY: aging work in progress, open branches, unmerged PRs, stale backlog
MOTION: context-switching, searching, navigating indirection to do one thing
EXTRA_PROCESSING: gold-plating, redundant checks, fidelity the consumer never perceives

# Method

FLOW_MAP: list steps start to finish
STEP_TAGGING: tag each step value-add, necessary-non-value, or waste with its waste type
COST_ESTIMATE: quantify time, effort, or latency per waste step
PRIORITIZATION: attack largest waste before most annoying
ELIMINATION_STYLE: remove waste outright, shrink or automate necessary-non-value, prefer elimination over optimization

# Output

VALUE_STATEMENT: consumer plus payable value in one sentence each
FLOW_TABLE: step, tag, waste type, rough cost
ELIMINATION_PLAN: largest waste first, each with concrete change and expected reclaim

# Reverse brainstorm

GUARD_NECESSARY: minimize compliance and irreducible setup rather than delete it
GUARD_BUSY: treat high activity as possible motion or rework, not value
GUARD_LOCAL_OPTIMUM: judge whole-flow effect, reject steps that grow downstream inventory or waiting

# Validation

DEFINITION_PRESENT: consumer and value stated before flow analysis
TAG_COMPLETENESS: every step tagged with class and, for waste, type
ORDER_CHECK: elimination plan sorted by reclaimed cost
